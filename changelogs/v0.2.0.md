# Geco 0.2.0 — Minecraft 1.21.1

- Restore normal Overworld terrain and add seeded marble deposits through loader biome APIs.
- Preserve handmade ebony trees for natural generation and saplings; protect obstacles, fluids and block entities.
- Fix wood and marble blockstate rotations, loot, tags, stripping and trapdoor crafting.
- Make data generation deterministic and correct loader metadata and compatibility bounds.
- Add layered tests, production JAR checks and validated Fabric/NeoForge publishing.

Worlds from unreleased builds can decode the old generator as vanilla noise terrain. Previously generated empty chunks are not rebuilt automatically.

Required: Architectury API on both loaders; Fabric API on Fabric.
